# AI 协作记录

本项目使用 Codex 与 TRAE 完成开发与验证。TRAE 负责主体模块的实现，使用时间为 2026-10-26 至 2026-10-30，共 7 轮开发对话；Codex 从 2026-10-28 起接手审查、修复、原始证据、相机专项验证、正版应用比较与提交整理。

| 工具 | 当前材料 | 记录依据 |
|---|---|---|
| Codex | [2026-11-08 正版与提交记录](codex-2026-11-08.md)、[2026-11-07 操作记录](codex-2026-11-07.md) | 实际需求、人工决定、测试输出及原始证据 |
| TRAE | [TRAE 使用记录](trae-record.md) | 7 轮任务的提示词、处理过程与运行结果 |

[开发提示词记录](development-prompts.md)按照实际项目任务整理需求、约束、人工决定和产物，条目采用统一格式。

每条协作记录写明任务目标、规格约束、AI 输出、人工取舍、测试反馈、修改结果和提交标识。现有 Git 修复历史可作为代码变化与回归的证据。

Codex 的原始证据保存在 `docs/reports/evidence` 目录，正文使用相对路径引用。TRAE 的会话历史保存在本机应用内，本目录保留任务与提示词摘要。
