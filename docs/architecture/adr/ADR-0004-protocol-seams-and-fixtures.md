# ADR-0004：协议抽象 + fixture 注入换取可测性

- 状态：接受
- 日期：2026-10-27

## 背景

三个现实约束：
1. iOS 模拟器**没有摄像头**，无法自动化测"拍摄"；
2. 系统权限弹窗无法被 XCUITest 稳定点击；
3. Vision OCR 有 ~1 秒延迟，UI 测试需要确定性等待点。

## 决策

把相机、权限、OCR、检测、导出全部抽象成协议；`AppServices.make(arguments:)`
根据启动参数选择真实现或测试替身（fixture 图、固定权限状态、内存存储）。

## 理由

- T04/T05/T06/T07 可以在无摄像头环境下端到端跑；
- T03 可以分别注入 `authorized/denied` 验证两条 UI 分支；
- 生产代码不含 `if debug`，替身只在装配层出现。

## 代价

- 多一层协议与一个装配点，读代码需要先看 `AppServices`。
- 测试路径与真实相机路径不完全相同 → 真机需补一次手工验收（已列入 acceptance）。

## 后果

UI 测试成为 CI 的常规门禁，而不是"有空再跑的奢侈品"。
