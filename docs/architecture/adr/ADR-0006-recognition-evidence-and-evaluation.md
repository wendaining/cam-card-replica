# ADR-0006：保留识别快照，区分文本门槛与图像测量

- 状态：接受
- 日期：2026-10-28
- 对应审查：R14、R15、R16

## 决策

BusinessCard 增加可选 recognition 快照，包含 OCRResult 和人工修改前的 ParsedCard。保持 Codable JSON；旧记录缺字段时解码为 nil。CardDraft 编辑保留快照，保存最终字段时不改原始证据。详情原文页可查看逐行置信度与最初字段/evidence。

保留既有理想文本首值测试及其门槛，明确标为历史回归指标，不把它称为图像准确率或完整多值准确率。另对理想文本检查所有缺失字段，对号码和邮箱比较完整集合；记录漏值与多值，不用首值掩盖错误。

将固定语料全部图片打包进测试目标，真实执行检测/校正/OCR/解析，按 GT 比较全部字段集合，输出每图明细并附在 xcresult。维度含语言、版式、字体、标签与照片/遮挡。所有源图片须执行成功并有文字，比较器用漏掉第二邮箱、多出号码、缺失字段被填的反例回归。

图像准确率是测量，不冒充确定性场景通过率；本次不降低原文本门槛，不为系统 Vision 的错字加入语料专用修补，不把识别率不足隐藏成“通过”。报告同时列全图片准确率、已印字段准确率和缺失字段误填率。尚未达到的概率目标继续明示。

扩展的理想文本检查发现既有“无标签传真误归座机”的已知限制（不是凭空生成号码）。该通用歧义在测试中用 XCTExpectFailure 显式标注，完整集合和误填统计照常计错，不能宣称全部字段幻觉率为零。有标签号码与非电话缺失字段仍必须全部断言通过。

## 语料版本

语料 v2 保留同一批50张虚构名片、76张图及业务 GT，改变确定性的字体分配：英文使用无衬线/衬线/等宽，中文与双语使用黑体/另一黑体/宋体。font_file 写入 GT/manifest，缺指定字体直接报错，避免默默回退成单字体。生成器同步九个 app fixture。发布时间元数据固定，重复生成连 GT 也字节一致。

比较 v1 与 v2 的图像数字时必须注明字体和图片改变；文本基准仍可直接回归，因为字段 GT 未变。真机拍照与正版 CamCard 对比仍需外部验收。

## 网站证据边界

v2 的 UI 反例证明，OCR 丢失 @ 后，邮箱可能变成合法的域名形状。保留完整主机名匹配，但只有网站标签或 www/http(s) 前缀才接受为网站；其他裸域名留在未归类文字，不能猜 @ 或根据 GT 决定。代价是无标签、无前缀的真实网站须人工补入。此规则不使用语料名字或特定字符纠错。
