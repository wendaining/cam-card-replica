# ADR-0002：字段抽取用规则引擎，不用大模型

- 状态：接受
- 日期：2026-10-27

## 背景

"OCR 文本 → 8 个字段"可以用 LLM（GPT/本地模型）或规则实现。
作业第八节的核心考点是"AI 不得补全不存在的信息"，并把字段抽取列为概率性功能。

## 决策

实现 `HeuristicFieldParser`：归一化 → 逐行分类（邮箱/网址/电话/地址/职位/机构/部门）
→ 打分选择 → 置信度阈值过滤。每个值保留 `evidence`。

## 理由

1. **可解释**：每个字段都能说清"为什么这么填"，答辩时能讲。
2. **可回归**：纯函数，50 张语料当单测，改一条规则立刻知道影响了哪些卡。
3. **不虚构**：阈值以下直接 `nil`，比 LLM 的"合理猜测"更符合 T09。
4. **无网络依赖**，演示现场不会因为断网挂掉。

## 代价

- 召回率低于 LLM（生僻版式、自由排版）。
- 词表需要维护（`KeywordTables`）。

## 后果

- 语料评测成为日常：`make bench`。
- 未来若要接 LLM，应作为"候选生成器"接在协议后，仍需阈值与人工确认，并单独评测幻觉率。
