# 产品规格：CamCard 名片数字化切片

> 状态：v1.0（2026-10-27）｜依据：课程作业第七～十三节 + 本机观察
> 编号规则：`7.x` 对应作业章节；`Txx` 对应验收测试。

## 0. 范围

**做**：名片夹 → 扫描/导入 → 检测校正 → OCR → 结构化 → 人工校正 → 保存 → 详情 →
搜索/标签/备注 → 持久化 → 导出。

**不做**：注册、会员、支付、广告、云同步、团队库、CRM/Salesforce、数字名片设计与模板、
QR 交换、邮件签名、会议录音、AI 商业分析。

## 1. 页面清单

| 页面 | 入口 | 关键状态 |
|---|---|---|
| 名片夹（`CardListView`） | 启动 | 空 / 有数据 / 无搜索结果 / 按标签筛选 |
| 扫描（`ScannerView`） | 名片夹右上角 + | 取景 / 权限被拒 / 无摄像头 / 拍摄中 / 失败 |
| 裁剪校正（`CropView`） | 拍摄或导入后 | 自动检测成功 / 失败退化为整图 / 手动拖角 |
| 识别中（`ProcessingView`） | 确认裁剪后 | 进行中 / 失败（可重拍） |
| 确认（`ReviewView`） | 识别完成 | 字段可编辑 / 低置信高亮 / 保存禁用（无姓名） |
| 详情（`CardDetailView`） | 点列表行 | 查看 / 编辑 / 删除 / 导出 |
| 原文弹层（`RawTextSheet`） | 确认页、详情页 | OCR 原文 + 行置信度 |

## 2. 功能规格

### 7.1 名片夹
- 7.1.1 无数据时显示空状态：标题「还没有名片」+ 说明 + 主按钮「扫描名片」。（T01）
- 7.1.2 有数据时按 `updatedAt` 倒序展示：姓名、`职位 · 公司`、首个号码、标签。
- 7.1.3 点行进入详情。（T13）
- 7.1.4 保存后列表立刻出现新名片（无需下拉刷新）。（T12）
- 7.1.5 删除后列表立刻消失。（T17）

### 7.2 拍摄与导入
- 7.2.1 首次进入请求相机权限；拒绝时显示说明与「请求相机权限」按钮，且不崩溃。（T03）
- 7.2.2 快门按钮 → 拍摄 → 进入裁剪。（T04）
- 7.2.3 相册导入 → 进入裁剪。（T05）
- 7.2.4 裁剪页可「重新拍摄」回到取景（丢失当前图）。（T06/T20）
- 7.2.5 中途「取消」退出整个流程，不写入任何数据。（T20）
- 7.2.6 模拟器无摄像头：显示替代说明，允许通过相册或测试名片继续。

### 7.3 边界检测与校正
- 7.3.1 自动检测矩形（长宽比 1.25–2.4），检测失败退化为整图。
- 7.3.2 四角可拖动，坐标限制在图片内。
- 7.3.3 确认后按四角做透视校正；校正失败时使用原图（不阻断流程）。

### 7.4 OCR
- 7.4.1 使用 Vision `accurate`，语言 `zh-Hans` + `en-US`，开启语言纠正。
- 7.4.2 保存原始文本（`rawText`）与逐行结果（文本、归一化坐标、置信度）。
- 7.4.3 OCR 失败不崩溃：提示后可重拍。

### 7.5 字段结构化
- 7.5.1 必填八字段：姓名、公司、职位、手机、座机、邮箱、网站、地址。
- 7.5.2 可选：部门、传真、备注、标签。
- 7.5.3 每个字段附 `confidence` 与 `evidence`（可解释性）。
- 7.5.4 多号码按 `手机/座机/传真` 分类；同类型可多个。（T10）
- 7.5.5 **不存在的信息必须为 `nil`，不得推测补全。**（T09）

### 9 人工确认
- 9.1 识别结果进入确认页，字段可逐项修改。（T11）
- 9.2 低置信字段（< 0.78）标「请确认」。
- 9.3 姓名为空时禁止保存。
- 9.4 取消返回名片夹，不产生任何记录。
- 9.5 显示「未归类文字」，供用户手动复制。

### 10 保存与详情
- 10.1 保存内容：原图、校正图、八字段 + 部门/标签/备注/原文/时间戳。
- 10.2 详情页展示全部已保存字段与图片；点号码拨号、点邮箱发信、点网站打开。（T13）
- 10.3 编辑姓名/公司后保存，详情立即更新并持久化。（T14）
- 10.4 删除需二次确认；同时删除本地图片。

### 11 搜索与标签
- 11.1 搜索匹配姓名、公司、职位、电话、邮箱、标签；纯数字查询忽略分隔符。（T15）
- 11.2 标签可创建、附加、按标签筛选、删除；删除标签同时从名片上移除。（T16）
- 11.3 备注可编辑，随名片持久化。

### 12 持久化
- 12.1 任何写操作立即落盘（JSON + 图片文件）。
- 12.2 杀进程重启后：名片、修改后的字段、标签、备注、图片全部还在。（T18）

### 13 导出
- 13.1 生成 vCard（.vcf）可分享。（T19）
- 13.2 可写入系统通讯录，字段映射：姓名→given/family、公司→organization、
  职位→jobTitle、手机→mobile、座机→work、传真→workFax、邮箱→work、地址→postal、网站→url。

## 3. 状态机

```
Scanner: 取景 --拍照/导入--> 裁剪 --确认--> 识别中 --成功--> 确认 --保存--> 名片夹
             ^                    |              |
             |                    | 失败          | 失败
             +---- 重拍 ----------+--------------+
Cancelled: 任意阶段取消 --> 名片夹（无副作用）
```

确认页状态：`canSave = name 非空`；保存成功 → 关闭流程；失败 → 留在页面显示原因。

## 4. 异常与边界（T20 汇总）

| 场景 | 期望 |
|---|---|
| 相机权限拒绝 | 显示说明 + 请求按钮，不崩溃 |
| 相册为空/取消 | 停留在扫描页，无副作用 |
| 检测不到矩形 | 使用整图继续 |
| OCR 无文字 | 确认页字段全空，可手填后保存 |
| 图片损坏 | 提示「无法读取照片」 |
| 保存时姓名为空 | 保存按钮禁用 |
| 存储写失败 | 提示「保存失败」，不静默丢失 |
