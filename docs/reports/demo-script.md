# 演示脚本与答辩准备

> 目标：**90 秒**讲完整个闭环，每一步都落到一条验收测试上；再准备 3 分钟版
> 应对"你再多讲点"的场面。
> 前提：模拟器已装好，App 已 build（`make build`），并提前 5 分钟打开过一次。

---

## 0. 演示前 3 分钟检查

```bash
make run                               # 编译、安装并启动模拟器 App
xcrun simctl launch --terminate-running-process 'iPhone 18 Pro' com.wendaining.CamCardReplica -fixture-camera YES
```

- **关掉网络**（证明全离线）：飞行模式 / 拔网线。系统设置里断网即可。
- 把「测试名片」按钮的位置记住（扫描页右下角，试管图标）。
- 备用：如果现场模拟器抽风，直接播提前录好的 30 秒录屏（`/tmp/camcard-shots` 截图可当静态版）。

## 2. 必须主动说出口的三句话

这三句是评分点，别等老师问：

1. **"确定性验收定义为20条；有自动化回归、模拟器真实进程重启和系统相册手动证据。真机与正版行为等价仍待签收，清单在 `docs/testing/external-acceptance.md`。"**
2. **"OCR 是概率性功能，我们没有追求逐字一致，而是做了量化评测：50 张语料、
   完整字段集合、漏值和多值，按语言、字体、版式和有无标签切分；缺失误填也照实统计。"**
3. **"审查发现保存失败后界面仍显示成功、删除写入失败却先删了图片。现在先提交 JSON 再发布状态或清理旧图，用失败注入和重启回读验证。"**

## 3. 3 分钟版：加讲的四段

### 3.1 为什么不用 SwiftData / 云 OCR / 大模型

- 数据量几十条，JSON 可直接打开、可 diff、删除名片能精确删图片；SwiftData 的
  迁移在两周作业里是纯风险。
- 云 OCR：结果随模型更新漂移，评测数字不可复现，演示还怕断网。
- 大模型抽字段：会有"合理猜测"，而作业第八节明确说**猜测就是错误**。

### 3.2 准确率怎么看

打开 `docs/reports/ocr-accuracy.md` 与完整图像报告：

- 理想文本历史门槛保留，同时列完整多值集合；
- v2 的50张 flat 图，姓名49/50、公司47/50、邮箱集合32/50；不能拿理想文本100%代表 OCR；
- 无标签号码缺少类型证据，仍可能归类错误。报告计错、界面要求人工确认；
- 全部76张图按语言、字体、版式、标签、图像种类切片，保留期望值与实际值。

讲清测量输入、计分单位和错误，比只报一个百分比更能说明结果。

### 3.3 可测试性怎么来的

`AppServices.make(arguments:)` 是唯一装配点。启动参数 `-ui-testing`、
`-fixture-camera`、`-camera-permission denied`、`-fixture-name zh-01`
让它切到内存存储 / 固定图片 / 固定权限。生产代码里没有 `if debug`。

### 3.4 SDD 怎么落地的

- 规格编号（`7.5.3`）→ `docs/spec/acceptance.md` 的追溯表 → 测试方法名 → 代码文件；
- 语料是脚本生成的，seed 固定，谁跑都是同一批图；
- 每个提交都是 Conventional Commits，改解析规则必须带测试。

## 4. 可能被追问的问题

| 问题 | 回答要点 |
|---|---|
| 为什么不用第三方 OCR？ | 见 3.1；核心是确定性与可复现性，另外作业不要求复现其专有算法 |
| OCR 准确率多少？ | 理想文本历史门槛、理想文本完整集合、全部76张图真实链路分开报告，按版本和环境说明。**不要只报一个数** |
| 怎么限制不瞎编字段？ | 阈值和 evidence 只是保护措施；现在检查完整字段与缺失误填，数字邮箱和丢 @ 的网站反例有回归，无标签号码歧义仍计错，不能宣称全部字段为零 |
| 数据怎么存的？ | `Application Support/CamCardReplica/library.json` + `Images/<uuid>.jpg`；先提交 JSON，成功后才发布内存或清理删除图片 |
| 多电话怎么区分？ | 标签优先 → 号码格式（1[3-9]、0 开头、400/800）→ 兜底低置信；同类可多个 |
| 杀进程真的还在？ | iPhone/iPad 独立文件库 terminate/launch UI 已验证字段、标签、备注与两图；真机上划关闭待补验 |
| 模拟器没摄像头，你怎么测拍照？ | 协议注入 fixture；真机路径是 `AVCaptureSession`，没改过 |
| 你和 CamCard 差多少？ | 功能闭环已实现；尚未锁定正版参考环境并观察，不能声称等价，差异清单在 `docs/reports/difference-analysis.md` 待填 |
| 哪些地方你认为做得不够？ | 竖排文字、强反光、一张图多张名片；这是下一阶段要做的 |

## 5. 演示失败时的兜底

1. 网络已断但仍失败 → 重启 App（`xcrun simctl terminate` + 重开），数据在磁盘上不会丢。
2. 模拟器起不来 → 用 `docs/reports/screenshots/` 里的 5 张截图讲完整流程。
3. 时间被压缩到 30 秒 → 只做：空态 → 扫描 → 确认页（讲"AI 输出≠数据"）→ 保存 → 列表现身。
