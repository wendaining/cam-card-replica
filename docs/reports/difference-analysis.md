# 与正版 CamCard 的差异分析

> 状态：**待补观察素材**（需要 iPad 上的正版 CamCard 截图/录屏）
> 方法一旦有素材即可填表，不需要改代码。

## 方法

1. 同一张名片（优先用 `TestData/cards/` 里的合成名片，避免真实个人信息）
   分别在 CamCard 与本 App 上走完整流程；
2. 按页面截图（名片夹 / 扫描 / 确认 / 详情）；
3. 逐项记录差异，归入四类：

| 类别 | 含义 | 处理原则 |
|---|---|---|
| 识别差异 | OCR 读错字（Cc 看成 Cc） | 记录，不追平（模型不同） |
| 归类差异 | 同一文本放到不同字段 | **优先修**，属于规格问题 |
| 补全差异 | 参考 App 填了、我们留空 | 我们坚持留空（T09），在报告里说明 |
| 交互差异 | 需要多一步/少一步操作 | 按规格权衡，记录理由 |
