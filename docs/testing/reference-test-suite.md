# 课程 Reference Test Suite：T01–T20

来源：[移动应用开发课程作业-v2.pdf](../../移动应用开发课程作业-v2.pdf) 第十七节（第 19–21 页）。下表为课程用例的语义整理，不是逐字转录，不是官网提供的测试套件，也不是执行通过记录。

黑盒观察提供参考行为；参考测试套件把行为变成可执行的验收条件。两者相关，但不能互相替代。课程已经给出这套基础用例，因此它的原始依据是课程 PDF。

| 编号 | 主题 | 操作/条件 | 预期 |
|---|---|---|---|
| T01 | 首次启动 | 首次打开无记录的 App | 显示空名片状态 |
| T02 | 进入扫描 | 从首页进入扫描 | 显示扫描界面 |
| T03 | 相机权限 | 分别允许和拒绝相机权限 | 响应符合规格，拒绝时有合理反馈 |
| T04 | 拍摄名片 | 拍摄标准名片并确认 | 进入识别流程 |
| T05 | 导入图片 | 从相册选择名片图 | 进入识别流程 |
| T06 | 边界检测 | 使用倾斜名片 | 检测并显示名片边界 |
| T07 | OCR 原文 | 识别名片 | 得到原始 OCR 文本 |
| T08 | 结构化字段 | 解析识别结果 | 姓名、公司、职位等按字段分类 |
| T09 | 缺失字段 | 识别没有网站的名片 | 不虚构网站 |
| T10 | 多电话号码 | 识别含 Mobile/Office/Fax 的名片 | 按类型归类 |
| T11 | 人工修改 | 修改识别结果后保存 | 保留人工修改值 |
| T12 | 保存返回 | 确认保存新名片 | 返回列表，新记录可见 |
| T13 | 查看详情 | 打开已保存名片 | 显示保存的字段 |
| T14 | 编辑名片 | 修改姓名、公司并保存 | 修改正确反映 |
| T15 | 搜索 | 按姓名、公司搜索 | 显示匹配名片 |
| T16 | 标签 | 给名片加标签，再按标签筛选 | 显示对应名片 |
| T17 | 删除 | 删除名片 | 从列表消失 |
| T18 | 持久化 | 保存后杀进程、重启并打开记录 | 记录及修改仍在 |
| T19 | 导出 | 保存到通讯录或导出 VCF | 姓名、公司、职位、电话、邮箱、地址映射正确 |
| T20 | 异常处理 | 取消、返回、拒绝权限、无法识别、空结果等 | 按规格响应，不破坏已保存数据 |

## 执行与判定

- 最终执行前记录参考 App 版本、iOS、设备或模拟器、语言、登录状态、免费功能范围及数据集；当前没有教师锁定基线的确认记录。
- 确定性行为应全部通过。OCR 和字段提取另用统一语料与 Ground Truth 计算准确率，保留错误案例；不要求任意输入与正版逐字符一致。
- T03 的权限注入证明本地拒绝状态；T04 的 fixture 注入证明后续流程。二者不证明真实系统授权弹窗或相机拍摄。
- T18 可在指定模拟器执行终止/重启；课程没有单独规定必须真机。
- T19 至少完成通讯录或 VCF 一种。当前交付使用 ContactsExporterTests 和 VCardDocumentTests 的自动化证据，不追加人工通讯录核对任务。
- 官网调研只能支撑其明确描述的行为，不能自动把未执行的用例记为通过。

本地步骤见 [测试计划](test-plan.md)，代码与测试映射见 [验收追溯矩阵](../spec/acceptance.md)，官网依据见 [调研与对比](../reports/difference-analysis.md)。人工验收按当前安排暂缓。
