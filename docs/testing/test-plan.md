## 手工验收清单（截图存档）

1. 真机相机：拍摄 → 检测 → 识别 → 保存，录屏 30 秒。
2. 真机权限：拒绝一次、允许一次。
3. 杀进程重启：保存后上滑 kill，重开核对 5 项。
4. 导出：保存到通讯录后在「通讯录」中核对姓名/公司/电话/邮箱/地址。
5. UI 对比：本 App 与参考 App 的名片夹/详情/确认页并排截图。
