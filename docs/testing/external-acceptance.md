## 必须有正版 CamCard

先填写参考环境：App 版本、iOS、设备、语言、登录状态、免费/会员范围、测试语料版本。当前均待观察，不猜测。

1. 同一张 v2 合成名片在两 App 逐步操作，保存首页/扫描/预览/裁剪/确认/详情截图。
2. 对 T01–T20 记录导航、取消、错误、编辑、删除、搜索/标签、持久化、导出行为。
3. 对同图的字段记录缺值、错值、多值和人工改动；把 OCR 差异与确定性交互差异分开。
4. 填写 difference-analysis 中的差异、决策、原因，并补规格/回归。未观察的条目保持“未验”。
