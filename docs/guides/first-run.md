# 第一次亲手用一遍（15 分钟）

> 面向：没写过 Swift、也没用过 iOS 模拟器的人。
> 目标：亲手走完本地闭环；真机与正版行为的签收另见外部验收清单。

---

## 0. 启动与测试图源

```bash
cd ~/Projects/mobile-app-dev/cam-card-replica

make run        # 编译 → 启动模拟器 → 装 App → 打开（约 30 秒）
make photos     # 把 50 张测试名片塞进模拟器相册（约 20 秒，只做一次）
make relaunch   # 杀进程再打开，用来验"数据还在"
```

`make run` 之后你会看到 **Device Hub** 窗口（Xcode 27 里替代了旧的 Simulator.app），
里面就是一台 iPhone 18 Pro；尚未保存过名片时显示空态。构建与安装共用 build 目录，可用 DERIVED_DATA_PATH 覆盖。

要使用下面的「测试名片」按钮，在模拟器上显式启用测试图源（仍使用文件库和真实 Vision）：

```bash
xcrun simctl launch --terminate-running-process 'iPhone 18 Pro' com.wendaining.CamCardReplica -fixture-camera YES
```

普通启动可直接用相册导入；真机正常启动使用摄像头。

> 鼠标点击 = 手指点击；键盘输入会直接进模拟器。

## 2. 走一遍完整流程（照着做）

### 第 1 步：扫一张名片 → 保存（约 40 秒）

1. 点右上角 **⊕**
2. 屏幕上会写「模拟器没有摄像头」——**这是预期的**。点右下角 **试管图标**（测试名片）
3. 进入**预览页**，点「使用这张」，再进入**裁剪页**：名片四角被蓝色框住，可以拖动任一角
4. 点 **下一步**
5. 等 1–2 秒，进入**确认页**：
   - 顶部是缩略图 + 本次识别置信度（随图片变化）
   - 姓名 / 公司 / 职位 / 部门 已自动填好
   - 往下滚：手机、手机+座机+传真、邮箱、网站、地址
   - 有的字段会带橙色 **「请确认」**——那是解析器不确定、让你核对的意思
6. 改一个字（比如姓名后面加个空格外的字），点右上角 **保存**
7. 回到列表，名片出现了 ✅

**这一步验证**：T01 空态、T02 入口、T04 的测试图源路径、T06 边界检测、T07/T08 OCR 与字段、T11 人工修改、T12 保存入列表；真实拍摄另验。

### 第 2 步：看详情、编辑、搜索、标签（约 40 秒）

1. 点刚存的名片 → **详情页**：图片、全部字段、标签、备注（T13）
2. 点右上角 **⋯** → **编辑** → 改公司 → 右上角 **保存** → 详情立刻更新（T14）
3. 返回列表，在搜索框输入刚保存名片的姓名片段 → 列表只剩匹配记录（T15）
4. 编辑时给名片添加标签并保存，清空搜索后点列表顶部的对应标签 → 只剩带这个标签的名片（T16）

### 第 3 步：删一张（约 15 秒）

详情页 → **⋯** → **删除** → 确认。返回列表，它消失了（T17）。

### 第 4 步：验证「杀进程数据还在」（约 30 秒）

```bash
make relaunch
```

App 被强杀后重新打开：名片、你改过的字段、标签、备注、图片全都还在（**T18**，作业里明确写
过「重启后数据丢失则该功能不能视为完成」）。

### 第 5 步：从相册导入（约 30 秒）

1. 先跑过一次 `make photos`
2. 点 ⊕ → 左下角 **相册图标**
3. 选一张合成名片；系统选择器按自身排序展示，不依赖文件名或固定位置
4. 选图后直接进入裁剪，后续与上面一样；系统选择器左上角关闭可取消选图

**这一步验证**：T05（真实相册路径）。斜拍的那几张尤其值得试——你会看到四角检测出来的
位置不是矩形，透视校正后才是正的。

## 3. 想验证「不瞎编字段」（T09，作业的重点）

1. 选一张**没有印网站**的名片（例如相册里名字像 `en-02` 的那种，名片上只有手机和传真）
2. 走到确认页，滚到「网站」——**必须是空的**
3. 如果它自己填了内容，那就是 bug

同理，「地址」「公司」在名片上没有时也应该是空的。

## 5. 常见困惑

| 你看到的 | 为什么 | 怎么办 |
|---|---|---|
| 「模拟器没有摄像头」 | 模拟器没有相机硬件，这是 iOS 模拟器的限制 | 用试管图标（测试名片）或相册导入 |
| 快门按钮是灰的 | 没有相机权限 / 没有测试图源 | 用试管按钮；真机才会弹权限框 |
| 网站 / 地址 是空的 | 名片上本来就没有这个信息 | 这是**正确行为**（T09，不许编造） |
| 传真被识别成手机 | 名片上那个号码没有 `Fax:` 标签，格式上无法区分 | 在确认页手动改；报告里有量化说明 |
| 列表下方一片空白 | 名片只有 3 张，列表到底了 | 正常 |
| 想看「一片空白都没了」的样子 | 删掉所有名片 | `make reset` 清空数据回到首次启动 |
| 中文/英文混排识别乱 | 极少数字体或艺术字识别不了 | 换一张；这是已知限制 |
