# 文档索引

| 目录 | 放什么 | 谁维护 |
|---|---|---|
| `spec/` | 产品规格、数据模型、验收追溯、**作业条款逐条核对**（`conformance-audit.md`） | 先改这里，再改代码 |
| `api/` | 服务协议与契约（OCR、检测、校正、解析、导出） | 改协议必须同步 ADR |
| `architecture/` | 架构总览 + ADR（每个决策一条，不复改） | 决策变了就新加一条 |
| `testing/` | 测试策略、测试计划、语料说明 | 加测试时同步 |
| `guides/` | 环境搭建、上手、提交规范 | 环境变了就更新 |
| `reports/` | 实测数据（OCR 准确率、错误分析、最终报告、演示脚本、截图） | 每次跑评测后追加 |

写作约定：
- 规格写"系统应当怎样"，不写"代码怎么写"。
- 每条规格带编号（如 `7.5.3`），`acceptance.md` 用它做追溯。
- 数字必须可复现：写清命令、日期、语料版本。
